# Product Requirements Document (PRD)

**Project Name:** CogniOS
**Author:** Shiv Dhakad
**Document Version:** 1.1.0
**Target Platform:** Web (Desktop & Mobile Responsive)
**Tech Stack Ecosystem:** React (TypeScript, Vite/Next.js), Tailwind CSS, shadcn/ui, Java 21, Spring Boot 3.x, PostgreSQL

---

## 1. Executive Summary & Problem Statement
**Problem:** Software engineers, particularly in the Java Full Stack ecosystem, face extreme fragmentation when tracking their career and learning progression. Academic records, GitHub projects, study notes, and technical competencies are scattered across university portals, local markdown files, browser bookmarks, and static resumes. This fragmentation severely inhibits knowledge retention, delays the generation of role-specific resumes, and makes it difficult to track true competency.

**Solution:** CogniOS serves as a premium, centralized "Personal Learning & Competency Hub". It operates as a digital second brain, combining an academic ledger, skill matrix, AI tool directory, project portfolio, and an automated resume generator into a unified interactive dashboard.

---

## 2. Goals & Success Metrics
### Primary Goals
*   **Centralization:** Consolidate skills, academic grades, courses, and project repositories into a single dashboard.
*   **Knowledge Retention:** Provide a structured "Second Brain" to document exact usage contexts for technologies, including trade-offs and alternatives.
*   **Career Readiness:** Enable 1-click generation of tailored, markdown-based resumes aligned with specific job roles based on selected database entities.

### Success Metrics (KPIs)
*   **Data Persistence:** 100% of CRUD operations successfully persist to `localStorage` (Phase 1) and PostgreSQL (Phase 2) without data loss on refresh.
*   **Resume Export Efficiency:** Time to generate a role-specific resume reduced from >30 minutes to <2 minutes.
*   **System Usability:** Achieve a load time of <1.5 seconds and seamless responsive behavior across mobile and desktop viewports.

## 4. Functional Requirements (Core Modules)

### Module 1: Command Center Dashboard
*   **Top-Level Metrics:** Display aggregate counts for Total Skills Mastered, Current GPA/Academic Average, Active Courses, and Resumes Created.
*   **Progress Visualization:** A dynamic "Java Full Stack Readiness" progress bar (0-100%).
*   **Activity Feed:** A timeline capturing the chronological addition of new skills, courses, or projects.
*   **Global Actions:** A universal search bar and "Quick Add" dropdown for logging new entities globally.

### Module 2: Skill Tree & AI Playbook
*   **Categorization:** Filterable tabs for Backend (Java/Spring), Frontend (React/Web), Databases/DevOps, AI & Tools, and Soft Skills (e.g., Impromptu Public Speaking).
*   **Competency Tracking:** Visual badges denoting proficiency (Beginner, Intermediate, Mastered/Production-Ready).
*   **The Playbook (AI Tool Registry):** A structured matrix detailing best use-cases, trade-offs, and alternatives (e.g., cataloging exact prompts for facial analysis object removal, or retaining exposure/contrast parameter fine-tuning).
*   **Proof of Work:** Deep linking to GitHub repositories or deployed apps demonstrating the skill.

### Module 3: Academics & Courses Ledger
*   **College Degree:** A tabular view mapping Semester, Subject Name, Credit value, and Grade. Includes a time-estimation tracker for study loads (e.g., automatically projecting 702 minutes needed to complete 234 practice questions).
*   **Online Courses:** Visual tracking cards for MOOCs featuring Platform Name, Progress Bar, and certificate hyperlinks.

### Module 4: Project Hub & Tailored Resume Builder
*   **Projects Gallery:** A grid showcasing built applications with titles, descriptions, and tech-stack badge tags (e.g., Smart Carpool System for SIH 2025).
*   **Tailored Resume Profiles:** Distinct job profiles (e.g., "Backend Engineer", "AI Tooling").
*   **Dynamic Selection:** Checkbox UI allowing the user to select specific skills, projects, and coursework relevant only to the current profile.
*   **Export Engine:** A modal preview compiling selected entities into a clean, text-based Markdown format, simulating PDF download.

### Module 5: Knowledge Library (Second Brain)
*   **Book/Docs Tracker:** Cards tracking technical literature, Author, Status (Reading/Finished), and external links.
*   **Takeaways & Code Snippets:** Markdown-supported text areas for retaining architectural diagrams, boilerplate code, and interview Q&A.

---

## 5. Non-Functional Requirements (NFRs)

*   **State Management & Persistence:** MVP relies on React `useState`/`useEffect` tied directly to browser `localStorage`. The app must initialize with a JSON "Seed Data" object if `localStorage` is empty.
*   **UI/UX Aesthetic:** Premium SaaS design language featuring "glassmorphism", backdrop blurs, and soft gradients. Strict adherence to `shadcn/ui` components and `lucide-react` icons.
*   **Branding:** The sidebar header must display "CogniOS" with the subtitle "by Shiv Dhakad".
*   **Responsiveness:** The sidebar must collapse into a hamburger menu on viewport widths under 768px.
*   **Theming:** Native support for system-preference Dark/Light mode toggling.

## 6. Technical Architecture & Data Schema

### Technology Stack
*   **Frontend:** React (Vite or Next.js), TypeScript, Tailwind CSS, shadcn/ui.
*   **Backend (Phase 2):** Java 21, Spring Boot 3.x (REST APIs), Spring Security (JWT), Spring Data JPA.
*   **Database (Phase 2):** PostgreSQL.

### Core Data Models (JSON / Relational Schema)
*   **Skill Entity:** `id`, `name`, `category`, `proficiencyLevel`, `bestFor`, `tradeOffs`, `alternatives`, `repoUrl`.
*   **Project Entity:** `id`, `title`, `description`, `stack[]` (Array of Skill IDs), `liveUrl`, `githubUrl`.
*   **Course Entity:** `id`, `title`, `platform`, `progressPercentage`, `certificateUrl`, `type`.
*   **Resume Profile Entity:** `id`, `jobRoleName`, `selectedSkillIds[]`, `selectedProjectIds[]`, `selectedCourseIds[]`.
*   **Library Item Entity:** `id`, `title`, `author`, `status`, `resourceUrl`, `keyTakeawaysMarkdown`.

## 7. User Stories

*   **US-01:** As a user, I want to view my overall competency breakdown on a dashboard to identify gaps in my Java Full Stack knowledge.
*   **US-02:** As a user, I want to record the trade-offs of a new AI tool I learned to easily recall when to use it during system design interviews.
*   **US-03:** As a user, I want to select specific frontend and backend projects from my gallery to generate a tailored resume for a Full Stack application.
*   **US-04:** As a user, I want my data to save automatically to my browser so that I don't lose my notes when I close the tab.
*   **US-05:** As a user, I want to quickly add a code snippet from anywhere in the app so I don't disrupt my current workflow.

## 8. Development Roadmap

### Phase 1: MVP (Frontend & Local Storage)
*   Scaffold React application via AI builder (Lovable).
*   Implement shadcn/ui design system and layout (Sidebar, Header, Routing).
*   Build all 5 core modules with `localStorage` CRUD operations.
*   Inject Java Full Stack seed data to simulate a live environment.
*   Implement the Dynamic Resume Checkbox and Export logic.

### Phase 2: Backend Integration (Java Spring Boot)
*   Initialize Spring Boot 3.x project with Spring Web and Spring Data JPA.
*   Define entity models and PostgreSQL database schema.
*   Develop REST endpoints (`GET`, `POST`, `PUT`, `DELETE` for all entities).
*   Swap frontend `localStorage` hooks with API calls.

### Phase 3: Advanced Features & AI
*   **AI Chat (Spring AI):** Implement an LLM assistant (via LangChain4j) trained on the user's "Knowledge Library" to answer specific technical questions based on their own notes.
*   **Spaced Repetition:** Add flashcard mechanics for interview prep algorithms.
*   **Public Portfolio Export:** Generate a read-only public Next.js portfolio directly from the dashboard data.
